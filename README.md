# Krisha Agent — персональный агент поиска квартир

Мониторит объявления о **покупке квартир** на **Krisha.kz** по твоим критериям, шлёт уведомления в **WhatsApp** и помогает согласовать с хозяином просмотр — **спрашивая у тебя дату и время** и **показывая каждое сообщение перед отправкой**.

## Как это работает

```
[cron] поиск на Krisha → отбор новых по критериям → 📲 уведомление тебе (с кодом)
   │
   └─ ты отвечаешь кодом объявления
        → агент находит телефон хозяина
        → показывает ПЕРВОЕ сообщение          → ты: «ок» → отправка хозяину
        → хозяин ответил
        → агент СПРАШИВАЕТ у тебя дату и время  → ты пишешь, напр. «суббота 15:00»
        → агент формулирует предложение хозяину → ты: «ок» / «ред: …» / «нет»
        → когда дата/время/место согласованы     → ты: «да» → подтверждение хозяину
```

## Что заложено в безопасность

- **Ты задаёшь дату и время** — агент никогда не придумывает их сам.
- **Ты одобряешь каждое сообщение** хозяину перед отправкой.
- **Финальное «да»** на встречу — только от тебя.
- Агент **честно представляется** автоматическим помощником.
- Агент **не обсуждает оплату, залог, паспортные данные** и ничего не переводит.
- Парсер ходит на Krisha **с задержками и лимитом страниц**, без нагрузки.
- Все ключи — в `.env`, в git не попадают.

> ⚠️ **Про Green API и отдельный номер.** Green API работает через автоматизацию WhatsApp и формально нарушает его правила — поэтому привязывай **отдельную SIM**, а не основной номер. Не используй для массовых рассылок: агент пишет только по твоей команде и ведёт одну переписку за раз — это снижает риск блокировки.

## 1. Требования

- Node.js **20+**
- Аккаунт **green-api.com** (есть бесплатный тариф)
- **Отдельная SIM** с установленным WhatsApp (это будет «личность» агента)
- Anthropic API-ключ (для диалога с хозяином)

## 2. Установка

```bash
cd krisha-agent
npm install
npx playwright install chromium
cp .env.example .env       # затем заполни .env (шаги ниже)
```

## 3. Настройка Green API (WhatsApp)

1. Зарегистрируйся на **green-api.com**, создай **инстанс**.
2. В кабинете возьми **idInstance** и **apiTokenInstance** → впиши в `.env`.
3. **Привяжи WhatsApp агента:** открой инстанс в кабинете → отсканируй QR-код телефоном с **отдельной SIM** (как при входе в WhatsApp Web).
4. В настройках инстанса включи **входящие уведомления** (incoming messages), чтобы агент получал ответы хозяев.
5. Webhook и туннель **не нужны** — агент сам опрашивает сервер Green API.

> Важно: номер на отдельной SIM (привязан к Green API) — это **отправитель**. А `MY_WHATSAPP` в `.env` — это **твой личный номер**, куда агент шлёт уведомления. Это **разные** номера: агент с SIM пишет тебе на личный и хозяевам.

## 4. Заполни `.env`

```
MY_WHATSAPP=77001234567        # твой личный номер (куда приходят уведомления), цифры без "+"
ANTHROPIC_API_KEY=sk-ant-...
GREEN_API_ID_INSTANCE=...
GREEN_API_TOKEN=...
```

## 5. Критерии поиска

Уже заполнены под тебя в `src/config.ts`: **покупка**, Алматы, районы (Жетысуский, Алмалинский, Бостандыкский, Ауэзовский, Наурызбайский), бюджет **до 35 млн ₸**, **1–2 комнаты**, площадь **от 35 м²**.

**Рекомендуется уточнить `searchUrl`:** зайди на krisha.kz, выставь фильтры руками, скопируй итоговый URL из адресной строки и вставь в `searchUrl` — так фильтры будут точно соответствовать сайту.

**Про селекторы парсера:** в `src/scraper.ts` (блок `SELECTORS`) классы карточек заданы по текущей вёрстке Krisha и могут устареть. Если объявления не находятся — открой страницу в DevTools и поправь селекторы.

## 6. Запуск

```bash
npm start          # мониторинг по расписанию + приём сообщений WhatsApp
```

Разовый прогон поиска без ожидания cron:
```bash
npm run once
```

## Шпаргалка: команды в WhatsApp

| Ситуация | Что прислать |
|---|---|
| Связаться с хозяином по объявлению | **код** из уведомления (напр. `1042`) |
| Отправить показанный черновик | `ок` |
| Отправить свой вариант текста | `ред: ваш текст` |
| Прекратить переписку | `нет` |
| Указать дату/время для предложения хозяину | напиши, напр. `суббота 15:00` |
| Подтвердить согласованную встречу | `да` |
| Отменить встречу | `нет` |
| Пропустить объявление | `пропустить` |

## Ограничения v1 (что можно доработать)

- **Одна активная переписка за раз** — пока идёт согласование по одной квартире, новую начать нельзя (защита от путаницы).
- **Телефон хозяина** парсится со страницы; если он скрыт или у номера нет WhatsApp — агент сообщит и предложит связаться вручную.
- Фото в уведомлении — пока 1 шт.

## Этика и право

- Парсинг — для личного использования; соблюдай разумную частоту и проверь условия Krisha.
- Агент обязан представляться автоматическим помощником — не убирай это из промта и первого сообщения.
- Green API — неофициальный канал: используй отдельную SIM и не делай массовых рассылок.
